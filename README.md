# SkyBlock Research Desk downloads

Windows app downloads and automatic update packages for SkyBlock Research Desk.

Download the latest **SkyBlock.Research.Desk.exe** from [Releases](https://github.com/Iron-and-Aether-Development/skyblock-research-desk-downloads/releases/latest). After installation, the app checks this release feed for updates when it starts.

The source repository is private. The distributed app package contains inspectable scripts and offline wiki data. No Hypixel developer key is included.
